# OOP Notes

A collection of detailed notes on **Object-Oriented Programming (OOP)** across multiple programming languages. This repository is intended for learning, revision, and reference—covering core OOP principles alongside how each language implements them.

## Topics Covered

The notes explore OOP concepts with explanations, syntax, code examples, comparisons, and practice questions, including:

- Classes and objects
- Fields, methods, and object state
- Constructors and constructor overloading
- Access modifiers and encapsulation
- Abstraction
- Inheritance and composition
- Polymorphism
- Method overloading and overriding (where supported)
- Static and final/readonly members
- Interfaces and abstract classes
- Object relationships: association, aggregation, and composition
- Language-specific features and differences
- Common mistakes and best practices
- Practice questions and revision checklists

> Topics and implementation details vary by language. The notes explain language-specific behavior instead of treating OOP as identical across C++, Java, JavaScript, and TypeScript.

## How to Use

1. Choose a language from the table above.
2. Read the concepts in the suggested order within that note.
3. Study the code examples and try rewriting them yourself.
4. Complete the practice questions without looking at the examples.
5. Use the revision checklist to identify topics you need to revisit.

## Purpose

These notes are my personal learning documentation for understanding OOP concepts and comparing how different languages approach object-oriented design.

They are written to be useful as a reference—not a substitute for experimenting with code, reading official documentation, and building projects.
